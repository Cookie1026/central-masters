# 結果PDFをスプレッドシートデータ化するまでの手順

## 1.PDFをPNG画像変換
### PDFには目に見えない隠れ情報が大量に入っているため、そのままOCRしても文字化けや文字欠損が発生してしまう。
### その回避策としてPNG画像変換することでノイズ情報を除去する。
#### [作業手順]
1. VSCODEでPDFを開く
1. ScreenShotボタン > All page を実行
1. 作成されたpngフォルダを移動して完了

## 2.文字起こし実行
#### [作業手順]
1. AIに`1-png2txt`を指示
    - .claude/commandsにSkillsがある
1. どのPNGファイルが対象か聞いてくるのでパスを教える

## 3.男女総合成績のCSVファイル作成
#### [作業手順]
1. TXTファイル（例：1-第78回PDFを文字起こし(AntiGravity).txt）を選択してAIに`2-txt2total`を指示
